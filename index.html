Welcome to LoongFire 欢迎使用 LoongFire

LoongFire is a community-driven, open-source firewall project ported from IPFire to support the LoongArch architecture. It delivers enterprise-level security features with full hardware compatibility for Loongson CPUs.

Advanced users can leverage eBPF technology through LoongFire for granular network control and observability.

For online documentation about IPFire, please refer to ipfire.org.
For Linux eBPF technology: ebpf.io.

LoongFire 是一个社区驱动的开源防火墙项目，基于 IPFire 移植，支持龙架构（LoongArch）。它为龙芯 CPU 提供企业级安全防护与完整的硬件兼容性。

高级用户可以通过 LoongFire 使用 eBPF 技术，实现细粒度的网络控制与可观测性。

关于 IPFire 的在线文档，请参考 ipfire.org。
Linux eBPF 技术：ebpf.io。

With contributions from Loongfans.cn and the IPFire community, IPFire has been officially ported to the LoongArch architecture. Project LoongFireLoongFire 项目

LoongFire is a community-driven project focused on bringing enterprise-grade firewall capabilities to the LoongArch architecture. Our mission is to make network security accessible to everyone through open-source collaboration.

Key Project Goals:

  • Full feature parity with IPFire
  • Optimized performance for Loongson processors
  • Simplified eBPF integration for users of all skill levels
  • Active community support and comprehensive documentation

Current Status: The project is actively maintained with regular updates. We're working on improving hardware compatibility and expanding our eBPF module collection.

LoongFire 是一个社区驱动的开源项目，致力于将企业级防火墙功能带到龙架构。我们的使命是通过开源协作，让网络安全对每个人都触手可及。

项目关键目标：

  • 与 IPFire 功能完全一致
  • 针对龙芯处理器优化性能
  • 为不同技术水平的用户简化 eBPF 集成
  • 活跃的社区支持和完善的文档

当前状态：项目正在积极维护并定期更新。我们正在改进硬件兼容性并扩展 eBPF 模块集。

LoongArch Port龙架构移植

The LoongArch port represents a significant milestone in bringing open-source firewall solutions to a broader range of hardware platforms. Our porting efforts include:

  • Full LoongArch64 architecture support
  • Optimized compilation for Loongson 3A series processors
  • Comprehensive testing on Loongson hardware

Supported Hardware:

  • Loongson 3A5000
  • Loongson 3A6000
  • Loongson 3C6000

Performance Highlights: The LoongArch port achieves near-native performance with optimized assembly routines and compiler flags specifically tuned for the architecture.

龙架构移植是将开源防火墙解决方案带到更广泛硬件平台的重要里程碑。我们的移植工作包括：

  • 完整 LoongArch64 架构支持
  • 针对龙芯 3A 系列处理器优化编译
  • 在龙芯硬件上全面测试

支持的硬件：

  • 龙芯 3A5000
  • 龙芯 3A6000
  • 龙芯 3C6000

性能亮点：龙架构移植通过针对该架构优化的汇编例程和编译器标志，实现了接近原生的性能。
