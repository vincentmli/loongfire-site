"LoongArch Has Arrived Around Us" — IPFire Officially Supports LoongArch

"龙架构已来到我们身边"——IPFire 正式支持龙架构

IPFire Maintainer Announces LoongArch Support

Recently, IPFire maintainer Michael Tremer published a LoongArch support announcement on the official IPFire blog. IPFire has begun releasing test images for LoongArch in parallel with its other supported architectures. LoongArch has become the 4th architecture supported by IPFire, after x86, ARM, and RISC-V — and the second newly supported architecture IPFire has added this year.

IPFire is a Linux-based open-source firewall distribution known for easy configuration and high security, suitable for a wide range of network environments. It can be built from source and integrates a rich set of additional features: a stateful inspection firewall, content filtering engine, Quality of Service (QoS), and VPN. Its design philosophy is easy setup and management, while continuously following security updates to ensure long-term stable and reliable operation.

Michael Tremer stated that the porting work was supported by a Loongson 3A6000 host, whose performance and usability performed well — a full global build of the IPFire system could be completed in about two hours.

A High Praise for Mainline Support

The blog post also highly praised the level of mainline support for LoongArch:

"LoongArch was the easiest port yet... partly because LoongArch did its homework: support is upstream in the Linux kernel, GCC and the rest of the toolchain, and pretty much everywhere else it needs to be. This is not an architecture in its early days. It has arrived." Translation: LoongArch was the easiest porting project for IPFire so far... Part of the reason is that LoongArch did its homework well: architecture support has already been upstreamed in the Linux kernel, GCC and other toolchain components, and various necessary components. LoongArch is not some "emerging architecture" — LoongArch has already arrived around us.

What This Means for the Ecosystem

Following general-purpose Linux distributions such as Debian and Alpine, IPFire — a specialized, application-oriented operating system — has once again broadened the software ecosystem and application scenarios of LoongArch. It verifies the practical value of LoongArch in professional fields such as security gateways and network equipment, and provides strong endorsement from the open-source community for Loongson's entry into the network equipment and enterprise security markets.

The personal recognition from an international project maintainer also sends a positive signal to global developers: LoongArch is an open, complete, and long-term reliable instruction set. From general-purpose systems to vertical applications, more and more international open-source projects are actively adapting to LoongArch — confirming that Loongson is moving from "usable" to "easy to use" and steadily integrating into the global open-source ecosystem.

IPFire 维护者发布龙架构支持公告

近日，IPFire 维护者 Michael Tremer 在 IPFire 官方博客上发布了龙架构支持公告。IPFire 已开始同步发布龙架构测试镜像。龙架构成为继 x86、ARM、RISC-V 之后，IPFire 支持的第 4 种架构，也是 IPFire 今年新增支持的第二种架构。

IPFire 是一款基于 Linux 的开源防火墙软件，功能强大，以配置简便、安全性高著称，适用于各种网络环境。IPFire 可以从源码构建，集成了状态检测防火墙、内容过滤引擎、服务质量（QoS）、VPN 等丰富的附加功能。其设计理念是易于设置和管理，同时持续跟进安全更新，确保系统长期稳定可靠运行。

Michael Tremer 表示，此次移植工作得到了一台龙芯 3A6000 主机的支持，其性能和可用性表现良好，完成一次 IPFire 系统的完整全球构建大约需要两小时。

对主线支持的高度评价

博客文章还对龙架构的主线支持水平给予了高度评价：

"LoongArch was the easiest port yet... partly because LoongArch did its homework: support is upstream in the Linux kernel, GCC and the rest of the toolchain, and pretty much everywhere else it needs to be. This is not an architecture in its early days. It has arrived." 译文：LoongArch 是 IPFire 迄今为止最轻松的移植项目……部分原因是 LoongArch 做足了功课：架构支持已在 Linux 内核、GCC 及其他工具链组件以及各种必要组件中上游化。LoongArch 不是什么"新兴架构"——龙架构已经来到我们身边。

这对生态意味着什么

继 Debian、Alpine 等通用 Linux 发行版之后，IPFire 作为一款专业应用型操作系统，再次拓宽了龙架构的软件生态与应用场景，验证了龙架构在安全网关、网络设备等专业领域的实用价值，为龙芯进入网络设备与企业安全市场提供了来自开源社区的有力背书。

来自国际项目维护者的个人认可，也向全球开发者释放了积极信号：龙架构是一个开放、完整、长期可靠的指令集。从通用系统到垂直应用，越来越多的国际开源项目正积极适配龙架构，印证了龙芯正从"可用"走向"好用"，稳步融入全球开源生态。
